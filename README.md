# 冒险岛翻译小助手 / 楓之谷翻譯小幫手

**MapleStory Classic World（CW）中文翻译工具** —— 完全免费、离线可用。

把游戏里的英文任务栏（Quest Helper）自动翻译成中文，整理成任务清单显示在游戏旁边。

## 功能

- 📜 **任务翻译**：自动识别 Quest Helper，翻译任务名称、要收集的道具和进度，完成的项目会打勾
- 📖 **官方译名**：名称和对话以台服官方译名为基础；简体版的常用地名、职业改成国服叫法（射手村、废弃都市、金币……）
- 🔌 **完全离线**：不用联网、不用账号、不花钱，没有 Claude / AI 账号也能用
- 🛡️ **安全**：只做屏幕截图和文字识别，不读取游戏内存、不修改游戏文件

## 使用方法

1. 解压整个文件夹（不要直接在压缩包里打开）
2. 先打开 MapleStory，建议使用「窗口模式」或「无边框窗口」
3. 双击 `冒险岛翻译小助手.exe`
   - 第一次打开可能要等 5～10 秒
   - Windows 若显示「已保护你的电脑」，点「更多信息」→「仍要运行」（程序没有数字签名，不是病毒）
4. 小助手会贴在游戏右边，显示绿色「● 离线翻译中」就是在运作了，打开游戏里的任务栏即可

详细说明请看压缩包里的「使用说明.txt」。
